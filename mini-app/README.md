# Mini-App

The browser client of Occupy Uranus (Telegram Web App). Entry point: `app-v1.html`; code in `js/`.

Documentation lives in [`docs/mini-app/README.md`](../docs/mini-app/README.md). It talks to the game only through [`api/game/`](../api/game/README.md).

`index.html`, `option*.html`, `test-local.html` and `style.css` are earlier prototypes and are not loaded by the app.
