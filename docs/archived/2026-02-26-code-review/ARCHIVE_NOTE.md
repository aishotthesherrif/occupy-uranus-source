## Why This Was Archived

The file `GAME_MECHANICS_REVIEW_LEGACY.md` describes a version of Occupy Uranus that included **Easy/Normal/Hard difficulty selection**.

**On 2026-02-27**, difficulty selection was removed from the game. All players now experience a single difficulty level (hardcoded to 'normal' internally).

This made the majority of the document inaccurate, as it extensively discusses:
- Starting resource comparisons across three difficulties
- Event frequency differences by difficulty
- Shop price multipliers by difficulty
- Strategic differences between difficulty levels
